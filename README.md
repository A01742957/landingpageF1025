# Impulse-X — Landing page F1025B

Landing page estática para GitHub Pages. No requiere Node.js, compilación ni dependencias.

## Publicar en GitHub Pages

1. Crea un repositorio en GitHub. Para una URL como `https://USUARIO.github.io/`, nómbralo `USUARIO.github.io`. Para una URL de proyecto, puedes usar cualquier nombre.
2. Descomprime este ZIP y sube **el contenido** de esta carpeta a la raíz del repositorio (deben quedar `index.html`, `styles.css` y `assets/` en la raíz).
3. En GitHub abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**.
5. Selecciona la rama `main` y la carpeta `/ (root)`, guarda los cambios.
6. Espera a que GitHub Pages termine la publicación. La URL aparecerá en esa misma sección.

## Personalización

- Mensaje principal: edita el `<h1>` en `index.html`.
- Colores oficiales: modifica las variables CSS al inicio de `styles.css`.
- Logotipos: reemplaza los archivos de `assets/` conservando sus nombres.
- La página está diseñada para escritorio y móvil.

## Archivos

- `index.html`: estructura de la página.
- `styles.css`: estilos y diseño adaptable.
- `assets/logo-circular.png`: logotipo circular principal.
- `assets/logo-horizontal.png`: firma horizontal.
- `assets/favicon.png`: icono del sitio.

Los logotipos incluidos se recortaron de la guía visual proporcionada para esta primera maqueta. Para producción, es preferible sustituirlos por los PNG originales con fondo transparente si están disponibles.
